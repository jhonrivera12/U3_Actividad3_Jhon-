\# Taller 3: Automatización de BD con Python, Faker y Git



Proyecto que automatiza la creación de una base de datos MySQL local e inserta 100.000 registros sintéticos utilizando SQLAlchemy y Faker.



\## Prerrequisitos

\- Python 3.10+

\- MySQL / DBeaver



\## Ejecución

1\. Instalar dependencias: `pip install -r requirements.txt`

2\. Configurar el archivo `.env` basado en `.env.example`.

3\. Ejecutar el script: `python main.py`
